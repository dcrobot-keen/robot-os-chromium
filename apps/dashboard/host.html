rover-01 host bridge — Phase 5

This page runs on the machine that can reach the firmware. It registers as the robot's host with the signaling server and then relays bytes between each remote operator's WebRTC data channel and a WebSocket to the firmware. It does not drive the robot and never sends heartbeats — the operator owns the heartbeat, so if an operator drops, the firmware watchdog zeroes the motors on its own ~300ms later. Open index.html in operator mode (same machine is fine for a first test) to connect to this bridge.
