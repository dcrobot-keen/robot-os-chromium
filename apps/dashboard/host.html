former-01 host bridge — Phase 5

Runs on the machine connected to the robot (the Former's own PC), or any machine that can reach the simulator. Registers as the robot's host with the signaling server, then relays bytes between each remote operator's WebRTC data channel and a transport to the controller. It does not drive the robot and never sends the keepalive — the operator owns it, so if an operator drops, the Roboteq serial watchdog zeroes the motors on its own ~1s later. (It does send the manifest's controller bring-up commands once per connect.)
